# Standard 5 Tamil Chapter 1 Content & Hierarchy Documentation

## 1. Curriculum Source & Authority
- **Curriculum Board**: Tamil Nadu State Board (Samacheer Kalvi)
- **Grade / Standard**: Class 5 (ஐந்தாம் வகுப்பு தமிழ்)
- **Unit / Chapter 1**: **Introduction to Tamil / தமிழ் மொழி அறிமுகம் & இலக்கணம்**
- **Core Themes**: தமிழ் எழுத்துக்கள் (உயிர் 12, மெய் 18, ஆய்தம் 1, மொத்தம் 247), இனவெழுத்துக்கள் (வல்லினம், மெல்லினம், இடையினம்), திருக்குறள் மற்றும் தொல்காப்பிய இலக்கண மரபு.

## 6. Security & Student Answer Protection
- **Authoritative Answer Sanitization (`toStudentQuestion`)**:
  - `isCorrect` stripped from all option objects.
  - `correctAnswer`, `solutionKey`, `answerKey` stripped before transmission to students.
  - Base64 check token `_ck` used for tamper-resistant client verification.
- **Answer Validation Endpoint (`POST /api/game/questions/:questionId/answer`)**:
  - Server-side authoritative validation against source question options.
  - Anti-tamper verification ensures question belongs strictly to `room-tam5-1`.
